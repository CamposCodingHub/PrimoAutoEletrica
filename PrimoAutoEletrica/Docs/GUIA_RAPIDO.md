# Guia Rápido - Primo Auto Elétrica

## Começando em 5 Minutos

### 1. Fazer Login

1. Execute o Primo Auto Elétrica
2. Use as credenciais padrão:
   - Email: `admin@primoautoeletrica.com`
   - Senha: `admin123`
3. **Importante:** Altere a senha imediatamente

### 2. Cadastrar Primeiro Cliente

1. Clique em **Clientes** no menu lateral
2. Clique em **Novo Cliente**
3. Preencha: Nome, Telefone, CPF
4. Clique em **Salvar**

### 3. Cadastrar Primeiro Veículo

1. Clique em **Veículos** no menu lateral
2. Clique em **Novo Veículo**
3. Selecione o cliente cadastrado
4. Preencha: Placa, Marca/Modelo, Ano
5. Clique em **Salvar**

### 4. Criar Primeiro Orçamento

1. Clique em **Orçamentos** no menu lateral
2. Clique em **Novo Orçamento**
3. Selecione cliente e veículo
4. Adicione produtos/serviços
5. Clique em **Salvar**

### 5. Aprovar e Iniciar Serviço

1. Selecione o orçamento criado
2. Clique em **Aprovar**
3. A ordem de serviço será criada automaticamente
4. Atribua um técnico e inicie o serviço

## Tarefas Comuns

### Venda Rápida no PDV

1. Acesse **PDV**
2. Digite o código ou nome do produto
3. Pressione Enter
4. Repita para adicionar mais itens
5. Selecione a forma de pagamento
6. Clique em **Finalizar**

### Buscar Cliente

- Use o campo de busca em qualquer módulo
- Digite nome, CPF ou telefone
- Pressione Enter ou clique na lupa

### Imprimir Documento

- Selecione o item (orçamento, ordem, etc.)
- Clique no botão de impressão
- Selecione a impressora
- Clique em OK

### Fazer Backup Manual

1. Acesse **Configurações** > **Backup**
2. Clique em **Criar Backup Manual**
3. Aguarde a conclusão

| Atalho | Ação |

| F1 | Ajuda |

| F5 | Atualizar lista |
| Ctrl+N | Novo registro |
| Ctrl+S | Salvar |
| Ctrl+F | Buscar |
| Ctrl+P | Imprimir |
| Delete | Excluir item selecionado |
| Esc | Fechar janela |

## Solução de Problemas Rápidos

### Não consigo fazer login

- Verifique email e senha
- Use as credenciais padrão se esqueceu
- Entre em contato com o administrador

### Sistema está lento

- Feche outros programas
- Verifique espaço em disco
- Reinicie o sistema

### Impressora não funciona

- Verifique se a impressora está ligada
- Verifique se há papel
- Configure a impressora em Configurações

### Backup falhou

- Verifique espaço em disco
- Verifique permissões
- Tente backup manual
