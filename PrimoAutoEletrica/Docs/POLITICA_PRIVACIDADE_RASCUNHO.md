## POLÍTICA DE PRIVACIDADE DO SISTEMA PRIMO AUTO ELÉTRICA

**Última atualização:** 17 de junho de 2026

### 1. Introdução

Esta Política de Privacidade descreve como o sistema Primo Auto Elétrica coleta, armazena e protege seus dados pessoais.

### 2. Dados Coletados

O sistema armazena os seguintes dados:
- **Dados de clientes:** Nome, CPF/CNPJ, telefone, e-mail, endereço
- **Dados de veículos:** Placa, marca, modelo, ano, chassi
- **Dados de serviços:** Descrição, valor, data
- **Dados financeiros:** Contas a pagar/receber, transações

### 3. Armazenamento de Dados

- Todos os dados são armazenados localmente em seu computador
- O banco de dados é criptografado em repouso
- Backups podem ser criados em locais externos configurados por você

### 4. Compartilhamento de Dados

- Não compartilhamos seus dados com terceiros
- Seus dados permanecem sob seu controle
- Exportação de dados é permitida a qualquer momento

### 5. Segurança

Implementamos medidas de segurança:
- Criptografia de dados em repouso
- Controle de acesso por usuário
- Logs de auditoria
- Validação de integridade

### 6. Seus Direitos

Você tem direito a:
- Acessar seus dados
- Corrigir dados incorretos
- Exportar seus dados
- Excluir seus dados
- Revogar consentimento

### 7. Retenção de Dados

- Dados são retidos enquanto você usar o sistema
- Você pode excluir dados a qualquer momento
- Backups podem ser configurados com política de retenção
