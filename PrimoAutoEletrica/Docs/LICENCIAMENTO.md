# Licenciamento - Primo Auto Elétrica

## Visão Geral

Este documento descreve o sistema de licenciamento do Primo Auto Elétrica.

## Tipos de Licença

### Trial (Avaliação)
- Duração: 30 dias
- Usuários: 1
- Funcionalidades: Todas
- Custo: Gratuito

### Single User (Usuário Único)
- Duração: 1 ano (renovável)
- Usuários: 1
- Computadores: 1
- Funcionalidades: Todas
- Custo: R$ XXX,XX/ano

### Multi User (Multi-usuário)
- Duração: 1 ano (renovável)
- Usuários: Até 5
- Computadores: Até 3
- Funcionalidades: Todas
- Custo: R$ XXX,XX/ano

### Enterprise (Empresarial)
- Duração: 1 ano (renovável)
- Usuários: Ilimitado
- Computadores: Ilimitado
- Funcionalidades: Todas + Suporte prioritário
- Cotação sob consulta

## Processo de Ativação

### 1. Obter Chave de Licença

Entre em contato com:
- E-mail: vendas@primoautoeletrica.com
- Telefone: (XX) XXXX-XXXX

### 2. Ativar Licença

1. Execute o sistema
2. A janela de ativação será exibida
3. Digite a chave de licença
4. Digite o nome da empresa
5. Digite o CNPJ
6. Clique em **Ativar**

### 3. Validação

O sistema validará:
- Chave de licença
- Hardware ID do computador
- Data de expiração
- Status de ativação

## Hardware ID

O Hardware ID é um identificador único do computador, gerado a partir de:
- Processador ID
- Número de série da placa-mãe
- Endereço MAC da placa de rede

O Hardware ID é usado para vincular a licença a um computador específico.

## Renovação de Licença

### Antes da Expiração

30 dias antes da expiração, o sistema exibirá uma notificação:
- Data de expiração
- Instruções para renovação
- Link para contato

### Processo de Renovação

1. Entre em contato com vendas
2. Pague a renovação
3. Receba nova chave de licença
4. Ative a nova chave no sistema

### Dados Preservados

Ao renovar a licença:
- Todos os dados são preservados
- Configurações são mantidas
- Histórico é mantido

## Transferência de Licença

### Para Novo Computador

Se você precisar transferir a licença para outro computador:

1. Entre em contato com suporte
2. Solicite transferência de licença
3. Forneça Hardware ID do novo computador
4. Receba nova chave
5. Ative no novo computador

### Taxa de Transferência

- Primeira transferência: Gratuita
- Transferências adicionais: R$ XX,XX

## Suporte

### Licença Trial

- Suporte por e-mail
- Tempo de resposta: 48 horas
- Documentação online

### Licença Paga

- Suporte por e-mail e telefone
- Tempo de resposta: 24 horas
- Documentação online

### Licença Enterprise

## Termos de Licença

### Uso Permitido

- Uso interno da oficina licenciada
- Instalação em computadores autorizados
- Acesso por usuários autorizados

### Uso Proibido

- Distribuição ou cópia do sistema
- Uso para fins comerciais externos
- Revenda ou sublicenciamento
- Engenharia reversa
- Modificação do sistema

### Garantia

O sistema é fornecido "como está", sem garantias expressas ou implícitas.

## Perguntas Frequentes

### O que acontece se a licença expirar?

O sistema continuará funcionando por 30 dias após a expiração. Após esse período, o acesso será bloqueado até a renovação.

### Posso usar a licença em mais de um computador?

Depende do tipo de licença:
- Single User: 1 computador
- Multi User: Até 3 computadores
- Enterprise: Ilimitado

### Perco meus dados se a licença expirar?

Não. Seus dados permanecem armazenados localmente. Ao renovar a licença, você terá acesso completo novamente.

### Posso cancelar minha licença?

Licenças são não reembolsáveis após a ativação.

### Como faço backup da minha licença?

A licença é armazenada em:
```
%LOCALAPPDATA%\PrimoAutoEletrica\Config\license_XXXXX.json
```

Faça backup deste arquivo junto com seus dados.
