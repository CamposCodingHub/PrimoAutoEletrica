# Checklist LGPD - Primo Auto Elétrica

## Visão Geral

Este checklist ajuda a garantir conformidade com a Lei Geral de Proteção de Dados (LGPD) no sistema Primo Auto Elétrica.

## Checklist de Conformidade

### 1. Base Legal

- [ ] Identificar base legal para cada tipo de dado coletado
- [ ] Documentar bases legais (consentimento, obrigação legal, contrato)
- [ ] Manter registro de bases legais atualizado

### 2. Consentimento

- [ ] Obter consentimento explícito quando necessário
- [ ] Permitir revogação de consentimento
- [ ] Documentar consentimentos obtidos
- [ ] Facilitar retirada de consentimento

### 3. Direitos do Titular

- [ ] Implementar direito de acesso
- [ ] Implementar direito de correção
- [ ] Implementar direito de exclusão
- [ ] Implementar direito de portabilidade
- [ ] Implementar direito de oposição
- [ ] Implementar direito de informação

### 4. Minimização de Dados

- [ ] Coletar apenas dados necessários
- [ ] Revisar periodicamente dados coletados
- [ ] Eliminar dados desnecessários
- [ ] Anonimizar dados quando possível

### 5. Segurança

- [ ] Criptografar dados em repouso
- [ ] Criptografar dados em trânsito (se aplicável)
- [ ] Implementar controle de acesso
- [ ] Implementar autenticação forte
- [ ] Implementar logs de auditoria
- [ ] Implementar monitoramento de segurança
- [ ] Testar segurança regularmente

### 6. Retenção de Dados

- [ ] Definir período de retenção para cada tipo de dado
- [ ] Implementar exclusão automática após período
- [ ] Documentar política de retenção
- [ ] Comunicar política ao usuário

### 7. Transferência Internacional

- [ ] Verificar se há transferência internacional de dados
- [ ] Garantir país de destino possui proteção adequada
- [ ] Implementar cláusulas contratuais padrão (se necessário)

### 8. Incidentes de Segurança

- [ ] Implementar plano de resposta a incidentes
- [ ] Definir procedimentos de notificação
- [ ] Notificar ANPD em até 72 horas
- [ ] Notificar titulares afetados
- [ ] Documentar incidentes

### 9. DPO (Encarregado)

- [ ] Nomear encarregado de proteção de dados
- [ ] Publicar informações de contato do encarregado
- [ ] Definir responsabilidades do encarregado
- [ ] Treinar encarregado

### 10. Transparência

- [ ] Criar política de privacidade clara
- [ ] Informar sobre coleta de dados
- [ ] Informar sobre uso de dados
- [ ] Informar sobre compartilhamento de dados
- [ ] Atualizar política regularmente

### 11. Relatório de Impacto

- [ ] Realizar relatório de impacto à proteção de dados
- [ ] Documentar riscos identificados
- [ ] Implementar medidas mitigadoras
- [ ] Revisar relatório periodicamente

### 12. Treinamento

- [ ] Treinar equipe sobre LGPD
- [ ] Treinar equipe sobre segurança de dados
- [ ] Documentar treinamentos
- [ ] Atualizar treinamentos regularmente

## Documentos Necessários
