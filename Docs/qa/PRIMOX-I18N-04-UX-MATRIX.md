## Legend

| Status | Meaning |
|--------|---------|
| **PASS** | User-visible strings for this category switch correctly to the target UICulture; residual pt-BR only where glossary allows (fiscal identifiers) |
| **PARTIAL** | Mixed: chrome/actions localized, but body/labels/dialogs/messages still show unintended pt-BR (or incomplete translation) |
| **FAIL** | Expected localized text stays in wrong language / broken keys / blank |
| **NOT TESTABLE** | Surface absent, blocked, or cannot be exercised in this environment |
| **PENDING_RUNTIME** | Not yet walked in live app for this language — **default until smoke** |

**Do not mark PASS from static XAML ~19%.** That metric is source coverage only.

**Business culture:** `CurrentCulture` / money / dates remain **pt-BR**; UICulture is what this matrix audits.

**Note:** Will be filled after I18n04 smoke/runtime. Initial marks are `PENDING_RUNTIME` (not PASS).

---

## How to fill

1. Run I18n04 smoke with UICulture = pt-BR, then en-US, then es-ES.
2. For each module × category, replace `PENDING_RUNTIME` with PASS / PARTIAL / FAIL / NOT TESTABLE.
3. Optional notes column may be added later; keep this file as the scoreboard.
4. Cross-check terms against the official glossary.
