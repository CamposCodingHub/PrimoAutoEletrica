# Manual do Usuario - Primo Auto Eletrica

Este manual foi feito para o uso diario da oficina. Ele explica os passos essenciais para instalar, acessar, cadastrar dados, vender, fechar caixa, importar NF-e, fazer backup e configurar permissoes.

## Ordem recomendada de leitura

1. Leia `01_INSTALACAO_E_PRIMEIRO_ACESSO.md` antes de instalar em uma maquina nova.
2. Leia `02_CADASTROS_CLIENTE_VEICULO_FUNCIONARIO.md` antes de cadastrar a base inicial.
3. Leia `03_ORCAMENTOS_OS_PDV_CAIXA.md` para operar a rotina comercial e de oficina.
4. Leia `04_NFE_BACKUP_RESTAURACAO_PERMISSOES.md` para operacoes administrativas e seguranca.

## Regras de uso seguro

- Faca backup antes de atualizacoes, restauracoes ou manutencoes no banco.
- Use perfis de acesso diferentes para administrador, caixa, estoque e mecanico.
- Cadastre cliente e veiculo antes de abrir orcamento ou ordem de servico.
- Confira os dados de caixa antes de fechar o dia.
- Guarde os arquivos PDF gerados quando forem enviados ao cliente.
